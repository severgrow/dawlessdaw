# First-run walkthrough (~60 seconds)

For Patryk. Plain English. Splot MIDI Brain in Chrome on the Mac.

1. Open **http://localhost:5173**. If Chrome asks for MIDI, click **Allow**.
2. If **Connect your rig** appears: follow the three steps, or **Close** and reopen later from **Settings → Ports & devices → Connect your rig…**.
3. Look at the top strip: one status line (not a pile of banners). **Panic** and **Jam (J)** are there.
4. Left rail has five tabs: **Play · Build · Sounds · Record · Settings**. Keys **1–8** still jump to the old panels (Rig, Controller, Sequencer, …).
5. **Play → Rig**: left-to-right map. **Motion** / **Drawings** toggles stay as before. Click **Live controller** (or key **2**) to route Circuit tracks.
6. **Build → Splot pattern**: modes **Circuit Live / Circuit Saved / Splot Pattern** (Circuit Mirror). **Song sections** for Project → SP/MPC.
7. Press **J** for Jam (big tiles + knobs + Panic). **Esc** or **J** again to leave.
8. **Settings → Tests** for bench cards. Turn on **Show experimental tools** only if you want Deep Sync.

Hardware check is optional on first run — assign Circuit in Setup when you’re ready to play.
